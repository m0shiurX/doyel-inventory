Approved implementation adjustment: attributes use `text=auto eol=lf`, rather
than unconditional `text eol=lf`. The unconditional rule immediately marks legacy
committed CRLF files modified; automatic handling preserves their current bytes
and sets LF for new text without silently normalizing the legacy application.
