## Implementation

The shared bootstrap starts sessions, sets Asia/Dhaka and E_ALL, loads config,
and includes procedural DB/auth/HTML helpers. PDO is lazy with ERRMODE_EXCEPTION,
FETCH_OBJ, utf8mb4, emulated prepares, stringified fetches and disabled multiple
statements. The plan's helper names/signatures are implemented. `db_tx` rolls
back and rethrows any Throwable. Config precedence is environment, optional
`config.local.php` return array, then the legacy defaults; an explicitly empty
environment password is preserved. The sample documents configuration keys.

Root and nested route guards redirect relative to the actual entrypoint. Admin
and JSON guards stop execution. Output escaping handles quotes, UTF-8 and null;
redirects use headers or a safely encoded JS fallback. Bootstrap output buffering
preserves the legacy logout response body while allowing its HTTP redirect.
Dashboard queries are parameterized and explicitly ordered by ItemID, with the
same markup and escaped displayed values. Menu includes do not redeclare helpers.

The report number-to-words helper initializes its global recursion counter per
call and uses integer division for modulo operands, avoiding PHP 8 numeric
conversion diagnostics. Resetting the counter also fixes the legacy state leak
between repeated calls; this is an intentional helper bug fix. Dashboard/logout
visible outputs are unchanged. Later report slices still compare their own labels.
