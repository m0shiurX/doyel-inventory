## Coverage and assertions

Nine requested flows cover sale/add/remove/post, oversell rejection, purchase and
new price, both-role collections/removal, cash and expenses, master-data CRUD,
both-role bill unpost/delete, stock snapshot and password change. Additional
coverage within those flows includes account edit, cash/expense deletions,
supplier payments and user creation. The README maps every write-only and mixed
write route to its scenario.

Assertions verify actual insert IDs, line counts, exact touched stock changes,
negative-amount role rules, delete effects, CRUD field changes and credential
re-login. Existing posted bill deletion captures headers, detail rows and stock
before/after, including the non-admin legacy bug. No SQL mutation substitutes for
the business handlers. Output queries have explicit columns and primary-key
ordering, restricted to new/touched records. Only write timestamps and verified
password hashes are masked. Numeric DB columns/aggregate fields trim fractional
trailing zeroes through string operations only, so FLOAT/DECIMAL representation
changes do not cause false diffs; no meaningful precision is dropped and no float
cast/rounding is used. Numeric-looking text remains untouched. UI formatting is
checked separately by the page characterization suite.
